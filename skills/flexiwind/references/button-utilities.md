## Button And UI Intents

Flexiwind button and UI intent utilities are centralized in `resources/css/flexiwind/intents.css`. Do not create or reference legacy project files such as `button-styles.css` or `ui-utilities.css`.

The generated main CSS file should reference the Flexiwind layers:

```css
@reference "./flexiwind/base.css";
@reference "./flexiwind/form.css";
@reference "./flexiwind/button.css";
@reference "./flexiwind/ui.css";
@reference "./flexiwind/utils.css";
@reference "./flexiwind/intents.css";
```

## Button Variants

Buttons are composed from:

- a variant utility such as `btn-solid`, `btn-soft`, `btn-outline`, or `btn-ghost`
- an intent utility such as `btn-solid-primary` or `btn-solid-destructive`
- the Blade component API: `<x-ui.button variant="solid" intent="primary">`

Supported public intents use `destructive`, not `danger`.

```css
@utility btn-solid-primary {
    --btn-color: var(--color-primary);
    --btn-fg: var(--color-primary-foreground);
}

@utility btn-solid-destructive {
    --btn-color: var(--color-destructive);
    --btn-fg: var(--color-destructive-foreground);
}

@utility btn-soft-primary {
    --btn-color: var(--color-primary);
    --btn-fg: var(--color-primary);
}

@utility btn-outline-gray {
    --btn-color: var(--color-background);
    --btn-fg: var(--color-foreground);
    --btn-border-color: var(--color-border);
    --btn-hover-color: var(--color-muted);
    --btn-ring-color: var(--color-ring);
}
```

## UI Variants

Badges, alerts, tags, and related primitives use the same intent approach with `ui-*` utilities.

```css
@utility ui-solid-primary {
    --ui-color: var(--color-primary);
    --ui-fg: var(--color-primary-foreground);
}

@utility ui-solid-destructive {
    --ui-color: var(--color-destructive);
    --ui-fg: var(--color-destructive-foreground);
}

@utility ui-outline-gray {
    --ui-color: var(--color-muted-foreground);
    --ui-fg: var(--color-foreground);
}
```

## Extending Intents

To add a custom intent:

1. Define a matching `btn-{variant}-{intent}` or `ui-{variant}-{intent}` utility in `resources/css/flexiwind/intents.css`.
2. Extend the relevant PHP helper map generated by the CLI.
3. Use the new intent through component props instead of scattering raw color classes through templates.
